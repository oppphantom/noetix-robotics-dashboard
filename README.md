# 松延动力 AI 数据工厂｜产品展示中心

This folder is the public GitHub Pages release package for the Noetix Robotics AI Data Factory product showcase.

Public URL: https://oppphantom.github.io/noetix-robotics-dashboard/

## Current Pages

- `index.html`: home page with product overview, robot visual, metrics, module entry cards, and embedded Demo video.
- `loop.html`: AI data factory closed-loop workflow.
- `dashboard.html`: 200-sample DEMO operating dashboard explanation.
- `architecture.html`: technical architecture, future roadmap, and transferability.
- `robots.html`: Bumi / N2 / E1 robot capability graph.
- `approval.html`: high-risk retry approval gate.
- `experience.html`: Feishu Base entry links and embedded Demo video.
